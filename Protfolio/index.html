Phantom Rescue Mesh

A decentralized emergency system that keeps working when networks fail.

Details
Problem
Disasters and remote areas often have no mobile network when people need help most.
Solution
Victims send SOS alerts over Bluetooth mesh; rescuers receive them with location and message.
Features
One-tap SOS, live GPS sharing, offline communication, real-time rescuer notifications, rescuer web dashboard
Technologies
Android Studio, Kotlin, Bluetooth LE and Mesh, GPS, Firebase, OpenStreetMap, Leaflet, Material Design
