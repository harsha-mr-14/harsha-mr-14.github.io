## 🌐 How to Publish Online (Free Hosting Options)

### Option 1: GitHub Pages (Recommended)
1. Log in to [GitHub](https://github.com/harsha-mr-14) and create a new public repository named:
   ```text
   harsha-mr-14.github.io
   ```
2. Upload the files from this folder (`index.html`, `styles.css`, `script.js`, and the entire `assets/` folder).
3. In your repository, go to **Settings** -> **Pages**.
4. Under **Branch**, select `main` (or `master`) and folder `/ (root)`, then click **Save**.
5. Your live portfolio will be instantly live worldwide at:
   ```text
   https://harsha-mr-14.github.io
   ```
